# TASK014 退款与售后测试政策

> 本文件仅用于 TASK-014 的真实 RAG 联调测试，不是生产业务政策。

## 退款申请窗口

TASK014-REFUND-WINDOW：测试订单在支付成功后的 7 天内可以申请退款。超过窗口后，前端和 Agent 均应提示不符合退款条件。

## 退款审核

提交退款申请后状态为 `PENDING_REVIEW`。`PENDING_REVIEW` 仅表示等待人工审核，不代表审核通过，也不代表退款已经完成。

## 售后材料

申请售后时需要提供订单号、SKU 编号和申请原因。退货退款还需要提供退货物流信息。

## 处理边界

所有退款金额、审核结果和最终状态由 Backend Service 决定。前端只展示后端返回值，不自行计算退款金额。
